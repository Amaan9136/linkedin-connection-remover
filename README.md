# LinkedIn Connection Remover

A lightweight Chrome extension that helps you efficiently manage and remove LinkedIn connections in bulk.

## 🚀 Features

- 🔍 Search connections by name or headline
- 🧠 Filter and sort connections
- ✅ Select individual or multiple connections
- ⚡ Bulk remove selected connections
- 🎯 Clean and simple UI inside LinkedIn
- 🛡️ Works only on LinkedIn connections page

## 🧩 How It Works

1. Injects a custom UI into the LinkedIn connections page.
2. Extracts your connection data (name, headline, etc.).
3. Allows selection and filtering of connections.
4. Automates the removal process with controlled delays.

## 📦 Installation

### Load Unpacked Extension

1. Download or clone this repository
2. Open Chrome and go to:
   chrome://extensions/
3. Enable Developer Mode
4. Click Load unpacked
5. Select the extension/ folder

## 🧪 Usage

1. Go to:
   https://www.linkedin.com/mynetwork/invite-connect/connections/
2. Open the extension popup
3. Launch the panel
4. Search / filter connections
5. Select connections to remove
6. Click Remove Selected

## ⚠️ Important Notes

- Use responsibly to avoid LinkedIn rate limits
- Removing too many connections too quickly may trigger restrictions
- This extension is not affiliated with LinkedIn

## 🔐 Permissions

- activeTab – interact with current tab
- scripting – inject scripts into LinkedIn page
- host_permissions – LinkedIn domain access

## 🛠️ Tech Stack

- JavaScript (Vanilla)
- Chrome Extension Manifest v3
- DOM Manipulation
